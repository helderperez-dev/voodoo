# Examples

Voodoo examples are executable documentation. They are organized as a learning
path rather than a flat catalog.

## Basics

- [Hello world](basics/hello_world/) — smallest Voodoo application.

## Web

- [Dashboard](web/dashboard/) — application UI and dashboard composition.
- [Realtime](web/realtime/) — realtime application behavior.
- [UI Magic](web/ui_magic/) — higher-level UI generation/composition.

## AI

- [AI agent](ai/agent/) — agent and tool fundamentals.
- [AI SaaS](ai/saas/) — AI-backed application composition.

## Adaptive systems

- [Operational closed loop](adaptive/operational_closed_loop/) — observation,
  goal, reconciliation and execution as a closed operational loop.

Future examples should fit one of the repository architecture domains:
`basics`, `web`, `data`, `ai`, `adaptive`, `distributed`, or `edge`.
